## 🧠 Overview

FemCare AI takes a patient's clinical, hormonal, and lifestyle data and predicts their risk of PCOS using a trained Random Forest model. Instead of returning a black-box result, it uses **SHAP (SHapley Additive exPlanations)** to show *which* features drove each prediction, making the output interpretable for both patients and healthcare practitioners.

> ⚠️ **Medical Disclaimer:** This project is for educational and research purposes only. Predictions are generated by a Machine Learning model and are **not** a substitute for professional medical diagnosis. Always consult a qualified healthcare provider.

## 🗂️ Dataset

The model is trained on a public PCOS clinical dataset from Kaggle with **541 patient records** and **43 features** per patient, across five categories:

- **Demographics & vitals:** age, weight, height, BMI, blood pressure, pulse
- **Hormonal profile:** FSH, LH, AMH, TSH, prolactin, beta-HCG, vitamin D
- **Menstrual & reproductive history:** cycle regularity/length, pregnancies, abortions
- **Lifestyle & symptoms:** weight gain, hirsutism, acne, hair loss, exercise, diet
- **Ultrasound findings:** follicle counts and sizes, endometrium thickness

Data preparation, EDA, model training, and evaluation are documented in [`notebook/FemCareAI.ipynb`](notebook/FemCareAI.ipynb).

## 📈 Model Performance

**Random Forest** was selected for deployment for its robustness on a small clinical dataset, computational efficiency, and compatibility with SHAP. XGBoost achieved the highest raw accuracy (93.58%), but Random Forest was chosen for these reasons.

| Metric | Score |
|---|---|
| Accuracy | 90.83% |
| Precision | 93.33% |
| Recall | 77.78% |
| F1 Score | 84.85% |
| ROC-AUC | 0.8752 |

## 🧩 How It Works

1. Enter patient data on the **Prediction** page.
2. The inputs are scaled and passed through the trained Random Forest model.
3. The model returns a risk label (High/Low) and a probability score.
4. Head to **Explainable AI** to see a SHAP-based ranking of the features that most influenced that specific prediction.
5. Check **Model Performance** to compare the deployed model against other algorithms.
